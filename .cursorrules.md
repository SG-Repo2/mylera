## Cursorrules

The following cursorrules govern how you (the LLM) transform or generate the code:

   - Do not remove or refactor business logic—only add or adjust UI/UX elements, styles, and animations.

2. **Consistent Coding Conventions**  
   - Maintain the existing import patterns and naming styles.  
   - Use existing references (e.g., theme variables, color sets) whenever possible.

3. **Modular Enhancements**  
   - Each enhancement (1–10) is self-contained.  
   - Changes in one file must not break or change the functionality in another file unless explicitly stated.

4. **Memory Leak Prevention**  
   - Whenever you introduce or edit an animation, ensure a cleanup routine is in place (`.stopAnimation()`, remove event listeners, etc.) if needed.

6. **Validation Steps**  
   - After every code snippet, you should confirm that the snippet aligns with the above rules.  
   - Summaries of changes must indicate potential testing approaches (e.g., “Tap on the MetricCard to see the refined press animation”).
